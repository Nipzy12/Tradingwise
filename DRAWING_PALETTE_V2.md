# Drawing palette mobile v2
- Mobile picker follows provided nine screenshots: full-height sheet, horizontal category tabs, three-column tool cards, Indonesian labels and search. Long press (520ms) or context menu opens a favorite action. Stars appear only on pinned tools. The Favorites tab groups pinned tools by category with a persistent show-on-chart switch.
- Fresh defaults have zero pinned drawings. Existing storage with the exact previous stock list [trend,horizontal,rectangle] and no migration marker is reset once; a custom list is kept. An old intentionally selected exact stock list cannot be distinguished and is reset. Other settings and drawings are untouched.
- New vector geometry and manual labeled patterns are independent implementations. Gann tools are anchor-relative approximations, curves/arcs are geometric; Path and Polyline accept 2–128 anchors, with explicit Finish or desktop double-click/Escape; other patterns keep their fixed anchor counts. No automatic harmonic/Elliott pattern validation, no live trade forecasts. VWAP uses HLC3 and available provider volume, volume profile assigns bar volume to HLC3 buckets (estimated, not tick-level), and no line is fabricated when data are missing. Coin/provider volume definitions vary. Visuals are local user-entered symbols, not an external sticker marketplace.
- Unsupported tools are deliberately omitted (e.g. exact Gann square variants, Fib spiral, Pitchfan, bar-pattern/ghost-feed, anchored screen text, table, image upload, external posts). Existing desktop picker and chart/provider code remain compatible; no cTrader activation. No APK binary rebuild is necessary for hosted WebView.

## Drawing behavior QA update
- Compact selected-object toolbar allows direct line color, integer width (1–20) and solid/dashed/dotted changes, saved through the normal undoable object update path.
- Path and Polyline keep all vertices as native price/UTC anchors (legacy fixed-count shapes migrate on load). Tap Finish on mobile; double-click or Escape finishes an open shape on desktop. Polyline can close by touching its first point after at least three vertices. Every vertex can be edited by handle or in properties. Limit: 128 anchors per shape.
- Fibonacci retracement and extension allow Reverse and Extend left/right; prior objects retain their original level orientation unless Reverse is enabled. The calculations remain linear-price, not logarithmic Fibonacci.
- Long/short labels and settings show planned entry, TP/SL percentages, RR, quantity, estimated profit/loss and balances. This is planning only, not live order execution or broker margin/fees.
- Automated catalog checks exercise placement, selection, duplication, undo/redo, deletion and SVG rendering for every supported drawing type. Mobile Chromium also verifies direct styling, seven-point Polyline, coordinate editing and reversible Fibonacci. Tests use deterministic candle fixtures; a real Android WebView and live data still require separate QA.

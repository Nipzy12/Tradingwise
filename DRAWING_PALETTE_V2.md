# Drawing palette v2
Layout follows supplied Android screenshots: Indonesian title, horizontal category tabs, three-column tile grid, search, long press/right click menu, gold star only after pinning, and persistent favorite toolbar switch. Fresh drawing favorites are empty; the exact old seeded trio is cleared on first read, while other saved lists are preserved. Other favorite collections remain unchanged.
New manually placed tools include circle, curve, Fib circles/time zones, ABC/impulse Elliott and XABCD/ABCD pattern guides, arrow markers, notes, flag, emoji/icon text. Pattern placement uses fixed anchor counts, not automated pattern validation; circles are screen-space geometry. Gann, regression, pitchfork, volume profiles, image upload, social posts and several other screenshot tools are not implemented. No inert fake buttons. Existing drawing tools and feeds retained.

# Drawing palette mobile v2
- Mobile picker follows provided nine screenshots: full-height sheet, horizontal category tabs, three-column tool cards, Indonesian labels and search. Long press (520ms) or context menu opens a favorite action. Stars appear only on pinned tools. The Favorites tab groups pinned tools by category with a persistent show-on-chart switch.
- Fresh defaults have zero pinned drawings. Existing storage with the exact previous stock list [trend,horizontal,rectangle] and no migration marker is reset once; a custom list is kept. An old intentionally selected exact stock list cannot be distinguished and is reset. Other settings and drawings are untouched.
- New vector geometry and manual labeled patterns are independent implementations. Gann tools are anchor-relative approximations, curves/arcs are geometric; shape paths are fixed anchor counts. No automatic harmonic/Elliott pattern validation, no live trade forecasts. VWAP uses HLC3 and available provider volume, volume profile assigns bar volume to HLC3 buckets (estimated, not tick-level), and no line is fabricated when data are missing. Coin/provider volume definitions vary. Visuals are local user-entered symbols, not an external sticker marketplace.
- Unsupported tools are deliberately omitted (e.g. exact Gann square variants, Fib spiral, Pitchfan, bar-pattern/ghost-feed, anchored screen text, table, image upload, external posts). Existing desktop picker and chart/provider code remain compatible; no cTrader activation. No APK binary rebuild is necessary for hosted WebView.

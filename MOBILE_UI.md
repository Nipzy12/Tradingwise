# Tradingwise mobile workspace
- At <=760 CSS px, the desktop bars are replaced by a compact header, full-height chart, scrollable horizontal tools, vertical favorites wheels, and mobile navigation. Desktop layout remains available at larger widths.
- Swipe pair/timeframe vertically; tap the active item for the full picker. Favorites are stored in existing workspace UI preferences. A manually selected nonfavorite stays visible until switching. First-use timeframe is D1; saved workspaces retain their selection. Unsupported Biquote 3m/2h intervals are excluded.
- Chart quote currency is based on provider metadata or recognized pair names. Conversion to selected fiat currencies uses Coinbase's public exchange-rate API, fetched on selection and cached for five minutes; it is a display-only fixed-rate estimate, not historical FX-adjusted OHLC. Failed/unsupported rates keep the prior currency. Underlying prices, order simulation, alerts, drawings, and strategy calculations remain in provider units. Unknown quote currencies cannot be converted.
- The Android app uses the live Vercel website, so UI changes normally appear on reopening without reinstalling. Device touch gestures and Android WebView export behavior still require on-device validation.
- Bottom navigation uses the existing watchlist, chart, symbol explorer, alerts and menu; it does not introduce a social network.
